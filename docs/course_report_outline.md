# 课程设计报告建议结构

## 1. 问题定义

- 任务是英文社交媒体文本的二分类教学实验，不是临床诊断。
- 说明正类标签来自数据集作者或启发式规则，标签定义在不同来源间并不完全一致。

## 2. 数据与质量控制

- 列出各数据源、许可、样本数、类别比例和文本长度。
- 说明清洗、语言过滤、SHA-256 文本指纹去重与近重复估计。
- 展示按 `source_id + label` 分层后的 train/validation/test 分布。

## 3. 方法

- TF-IDF、长度统计、VADER 情感和 EMNLP'17 词典弱特征。
- Logistic Regression、LinearSVC、树模型和 MiniLM 对比。
- 解释验证集如何拆分为概率校准子集与阈值选择子集。

## 4. 实验结果

- 主表同时展示同域测试与跨数据源测试指标。
- 报告 F2、Specificity、MCC、Brier score 和 bootstrap 95% 置信区间。
- 使用 `ablation_results.csv` 说明每类附加特征的实际贡献。

## 5. 错误分析

- 从 `error_cases_test.csv` 分析假阳性、假阴性、短文本、反讽和引用他人经历。
- 对比同域 F1 与跨域 F1，解释数据来源偏差和词汇分布变化。

## 6. 系统实现

- 描述 SQLite 数据层、统一 Pipeline、模型产物元数据、批量推理与 Tkinter GUI。
- 展示模型版本、输入限制和非医学用途声明。

## 7. 伦理与局限

- 讨论误判、污名化、隐私、标签噪声和训练语料代表性。
- 明确系统不能用于医疗决策、危机分诊或自动处罚。
- 对自伤危险只提供固定的紧急求助提示，不由模型替代人工判断。
