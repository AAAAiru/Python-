## 四、核心原理速记

### 1. TF-IDF 是什么？

TF 表示一个词在当前文本中出现得多不多，IDF 表示这个词在所有文本中是否少见。一个词在当前文本常见、但在整个语料中少见时，权重较高。

### 2. 逻辑回归做了什么？

它对所有特征计算加权和：

`z = w1*x1 + w2*x2 + ... + b`

再使用 sigmoid 映射到 0 到 1：

`score = 1 / (1 + exp(-z))`

### 3. 为什么使用 F2？

`F2 = 5 × Precision × Recall / (4 × Precision + Recall)`

F2 对召回率的重视程度高于精确率，适合观察模型是否漏掉较多阳性样本。

### 4. 为什么不固定使用 0.5？

0.5 只是默认阈值，不一定适合当前任务。项目在独立验证子集上搜索使 F2 最大的阈值。

### 5. Platt Scaling 是什么？

它使用另一层逻辑回归学习“原始模型分数”和“实际标签频率”之间的关系，用于缓解分数过度自信。它改善的是分数尺度，不会让模型自动理解更多语义。

### 6. 为什么最终选择逻辑回归？

不是因为它同域成绩最高，而是因为它在同域 F2 和跨数据源 F2 的综合评价中最好，且训练快、易保存、适合普通电脑。

### 7. GUI 档位和模型有什么关系？

模型先输出阳性分数，再按 0.35 和 0.70 显示低、中、高三档。界面还包含针对明确危机表达、强困扰表达、明显积极语境和短文本的展示规则。规则是教学层保护，不是医学结论。

### 8. 最大的实验局限是什么？

同域 F2 约为 0.945，但跨数据源 F2 约为 0.717，说明模型对数据来源和语言风格敏感。

## 五、老师高频追问

### 为什么不用深度学习？

> 课程设计优先考虑普通电脑可运行、训练速度和可解释性，因此以 TF-IDF 和经典模型为主线。项目预留了 MiniLM 对比模块，但当前完整实验因 `sentence-transformers` 可选依赖缺失而跳过，所以我们没有把它包装成已完成成果。

### 你们的数据是否平衡？

> 合并后阳性 3,840、阴性 3,807，整体基本平衡。Pipeline 中保留了 RandomOverSampler 和 balanced class weight 作为统一实验策略，但在当前数据上的平衡作用有限。

### 为什么同时使用过采样和 class weight？

> 这是统一实验 Pipeline 的设计选择，但当前数据接近平衡，因此可能存在策略冗余。课程设计中保留它用于模型对比，后续应通过单独消融判断是否同时使用更合理。

### 为什么准确率只有 88.8%，AUC 却有 97.7%？

> AUC 衡量所有阈值下的排序能力，准确率取决于某一个具体阈值。我们为了提高召回率选择了偏低的 F2 阈值，因此会增加假阳性并降低准确率和特异度。

### 90% 是不是患病概率？

> 不是。它是经过校准的模型阳性分数，表示文本与训练数据阳性语言模式的接近程度。数据标签不是临床诊断，因此不能解释为患病概率。

### 为什么跨域结果下降？

> 两个数据源的文本长度、写作方式和标签构造不同。模型学到了一部分来源特有的词语分布，所以更换来源后性能下降，这说明需要更多独立数据做外部验证。

### 词典是不是模型解释？

> 词典命中可以作为文本证据，但不是因果解释。最终逻辑回归同时使用 TF-IDF 和辅助特征，不能只根据一个词说明模型为什么得出结果。

### 你们如何避免数据泄漏？

> 使用规范化文本指纹去重，并检查训练、验证、测试之间没有指纹重叠；切分完成后再拟合 TF-IDF；校准和阈值选择使用验证集的不同子集。

### 为什么使用 SQLite，不直接使用 CSV？

> CSV 仍用于导出和人工检查，SQLite 用于统一保存样本、来源、切分和元数据，方便程序查询和保证数据构建过程可追溯。

### 这个系统能检测中文吗？

> 不能。当前预处理、VADER、词典和训练数据均面向英文，GUI 也会检查拉丁字母比例。中文处理属于后续方向。

### GUI 有没有上传文件和批量检测？

> 当前 GUI 只支持单条文本。项目另有命令行 CSV 批量推理脚本，但没有在 GUI 中实现文件上传。

### 你们是否使用了 AI 编程？

> 开发过程中使用了 AI 作为编程辅助工具，用于生成代码草稿、排查错误和整理文档。选题、数据收集、需求边界、实验运行、指标核对、误判案例复现和最终方案取舍由我们完成。我们不把 AI 生成内容直接视为正确结果，而是通过测试和实验产物进行验证。

### 如果老师问到没有研究的细节

不要编造，可以回答：

> 这个细节我们没有单独做实验，因此不能直接下结论。当前项目实际采用的是……，我们已经验证的是……；如果继续完善，会通过……实验进行比较。

这种回答比绕回熟悉模块更可信。

## 六、成员分工回答

> 萧准主要负责课题方向确定、前期调研、需求分析和初步方案构想；任冉主要负责两个公开数据集的收集、筛选、整理和统计核对。在实现阶段，我们共同使用 AI 辅助编程完成数据管道、模型实验和 GUI，并共同进行测试案例复现、结果核对、报告撰写和答辩准备。我们的分工有侧重，但核心方案和最终验收是共同完成的。
