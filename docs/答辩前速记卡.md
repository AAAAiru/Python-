# 答辩前速记卡

## 六分钟节奏

- 萧准：开场、背景流程、模型选择、总结，约 2 分 20 秒
- 任冉：数据、特征、工程优化、结果、GUI，约 3 分钟
- 预留约 40 秒用于换页和停顿
- GUI 只演示一条文本，最多 15 秒

## 五个数字

- 两个实际数据源
- 总样本 7,647
- 训练 / 验证 / 测试：4,893 / 1,224 / 1,530
- 同域测试 F2：0.945
- 跨数据源 F2：0.717

## 一条技术链路

CSV → 清洗与指纹去重 → 来源和标签分层切分 → TF-IDF + 统计 + VADER + EMNLP 词典 → 逻辑回归 → Platt 校准 → 阈值 → Tkinter GUI

## 为什么选逻辑回归

逻辑回归不是同域最高，但在 `0.7 × 同域 F2 + 0.3 × 跨域 F2` 的综合选择中最好，且适合普通电脑。

## 分数怎么来

特征加权和 → sigmoid 原始分数 → Platt 校准 → 模型阳性分数。

模型阳性分数不是患病概率。

## F2 为什么重要

F2 比 F1 更重视召回率，用于减少阳性样本漏判，但代价是误报增加。

## GUI 真实功能

- 单条英文文本输入
- 模型阳性分数
- 低 / 中 / 高文本提示档位
- VADER 情感值、词典证据和模型版本
- 危机表达安全提示
- CSV 批量推理只在命令行，不在 GUI

## 不能说的内容

- 不能说使用了 RoBERTa
- 不能说支持中文或多语言
- 不能说 GUI 支持文件上传
- 不能说有 train.db、val.db、test.db
- 不能说标签是临床诊断
- 不能把模型分数叫患病概率
- 不能说逻辑回归同域成绩最高

## 最大局限

数据主要来自 Reddit，跨数据源性能下降，说明泛化能力有限。

## AI 辅助开发回答

使用 AI 生成代码草稿和排查问题，但选题、数据收集、实验运行、结果核对、误判复现和最终取舍由成员完成。

## 分工

- 萧准：选题、调研、需求分析、初步构想
- 任冉：数据集收集、整理、统计核对
- 共同：AI 辅助实现、模型实验、GUI 测试、报告和答辩
